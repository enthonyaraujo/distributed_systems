# Descrição:

O projeto final da disciplina visa capturar as competências de conhecimento adquiridas no curso de Sistemas Distribuídos. Sendo assim, esta atividade individual inclui:

- Arquitetura de três camadas (apresentação, negócios e dados);
- Comunicação entre componentes utilizando APIs (estilo arquitetônico baseado em recursos);
- Configuração do DNS para acesso à aplicação via SEUNOME.grupo?.sd.ufersa.dev.br e à API via api.SEUNOME.grupo?.sd.ufersa.dev.br;
- Autenticação de usuário e autorização de chamadas à API.

O discente deverá apresentar as funcionalidades do projeto final em sala de aula ao docente no dia 27/11/2026.
